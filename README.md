# Homestead Defense (working title)

Low-poly homesteading city defense game. Design spec: [docs/game-master-spec.md](docs/game-master-spec.md). Path from current state to a Steam-viable MVP: [docs/roadmap_steam_mvp.md](docs/roadmap_steam_mvp.md).

## Requirements

- [Godot 4.3+](https://godotengine.org/download)

## Running

Open this folder as a project in the Godot editor (`Project > Import`, select this directory's `project.godot`), then press Play (F5). Boots to a main menu (New Game / Continue / Settings / Quit) rather than straight into gameplay.

- [ ] **Known v1 tradeoff, deliberate:** villagers/buildings/enemies still place at a flat y=0 (this file's own header comment: "Gameplay stays on the y=0 plane" - `BuildManager`'s ghost placement raycasts a math plane at y=0, not real terrain height, so full terrain-conforming placement would be a bigger follow-up, not a quick add). Elevation amplitude is kept modest specifically so this doesn't read as buildings floating/sinking - a gentle rolling/terraced texture, not dramatic hills.
